# Documentação

Arquivos principais:

- `MEMORY_RULES.md`: regras que o GPT deve seguir ao usar a memória.
- `GPT_INSTRUCTIONS.md`: instruções para colar em um GPT personalizado.
- `CHATGPT_SETUP.md`: passo a passo para configurar no ChatGPT via GPT Actions ou MCP remoto.
- `USAGE.md`: exemplos HTTP e MCP.
- `DEPLOY.md`: deploy em VPS com Docker Compose, Caddy e GitHub Actions.
